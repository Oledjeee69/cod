# Использование ИИ (Cursor / Claude) в проекте

| Область | Что сделал ИИ | Что проверял / правил человек |
|---------|---------------|-------------------------------|
| Каркас проекта | Vite, SCSS-структура БЭМ, `vite.config.js` с копированием в WP | Структура папок, скрипты npm |
| HTML-разметка | Семантический каркас секций, meta/OG, JSON-LD | Соответствие ТЗ, тексты |
| SCSS | Переменные, миксины, блоки header/hero/calculator | Токены под макет после экспорта PNG |
| Калькулятор JS | Логика range/input, формула аннуитета, JSON alert | Границы полей, UX ввода сумм |
| Бургер-меню | JS + классы `nav--open` | ARIA, закрытие по клику на ссылку |
| WordPress | `functions.php`, шаблон `page-landing.php`, enqueue dist | Установка на WP, module script |
| Docker / CI | GitHub Actions для Pages | URL репозитория в `homepage` |
| Документация | README, AI_USAGE, design/README | Факты доступов, инструкции |

## Почему выбран такой подход

1. **Vite + vanilla** — быстрая сборка, удобно для Pixel Perfect и переноса в WP без SSR.
2. **Отдельная WP-тема** — соответствует пункту «интеграция на CMS», при этом статический demo для ревьюера.
3. **ИИ для рутины** — бойлерплейт, повторяющиеся блоки, документация; визуальная подгонка — по PNG из Figma.

## Что доработать после получения макета

1. Сверить отступы и цвета в Perfect Pixel с `design/desktop.png` / `design/mobile.png`.
2. Заменить SVG-заглушку авто на экспорт из Figma.
3. Уточнить формулу платежа, если в ТЗ указана другая ставка.
