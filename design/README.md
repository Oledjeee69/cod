# Референсы макета FMF-Test

Положите сюда экспорты из Figma для сверки Pixel Perfect:

- `desktop.png` — макет 1440px
- `mobile.png` — макет 375px
- `tablet.png` — опционально
- `assets/` — экспорт иконок и изображений

Текущая вёрстка выполнена по типовой структуре лендинга лизинга (калькулятор + hero). После добавления PNG сверьте отступы в Perfect Pixel и при необходимости подправьте токены в `src/scss/_variables.scss`.
